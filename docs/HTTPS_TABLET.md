# HTTPS و نصب «ماد» روی تبلت

مرورگر فقط در **HTTPS** (یا روی `localhost`) اجازه‌ی Service Worker و نصب PWA را می‌دهد. بدون HTTPS، روی تبلت
صفحه باز می‌شود ولی حالت آفلاین و «نصب برنامه» کار نمی‌کند. بسته به وضعیت شما یکی از دو مسیر را بروید.

> این راهنما و تنظیمات برنامه روی شبکه‌ی شما آزمایش نشده است. اگر در هر مرحله خطایی دیدید، متنش را بفرستید.

## مسیر الف: شبکه‌ی داخلی خوابگاه، بدون دامنه (برای آزمایش و استفاده‌ی داخلی)

سرور (همان کامپیوتر ویندوزی که برنامه روی آن اجرا می‌شود) باید یک **IP ثابت** داخل شبکه داشته باشد (مثلاً `192.168.1.20`).

1. [mkcert](https://github.com/FiloSottile/mkcert/releases) را دانلود کنید (فایل `mkcert-...-windows-amd64.exe`، برای راحتی به `mkcert.exe` تغییر نام دهید).
2. در PowerShell داخل پوشه‌ی پروژه:
   ```
   .\mkcert.exe -install
   .\mkcert.exe -key-file certs\mad-key.pem -cert-file certs\mad.pem 192.168.1.20 localhost
   ```
   (به‌جای `192.168.1.20` آی‌پی واقعی سرور را بگذارید. پوشه‌ی `certs` را از قبل بسازید و در Git/زیپ‌ها نگذارید.)
3. در `.env`:
   ```
   HTTPS_KEY_FILE="./certs/mad-key.pem"
   HTTPS_CERT_FILE="./certs/mad.pem"
   PORT=3443
   ```
4. اجرا: `npm run start:dev` و آزمایش در همان کامپیوتر: `https://192.168.1.20:3443`
5. در فایروال ویندوز اجازه‌ی ورود به پورت `3443` را بدهید (Windows Defender Firewall → Inbound Rules → New Rule → Port).
6. **گواهی ریشه را روی تبلت نصب کنید** تا تبلت به این گواهی اعتماد کند. فایل ریشه با `.\mkcert.exe -CAROOT` پیدا می‌شود (`rootCA.pem`).
   - **اندروید:** فایل را به تبلت منتقل کنید؛ Settings ← Security ← Encryption & credentials ← Install a certificate ← CA certificate.
   - **آیپد:** فایل را (با نام `rootCA.crt`) با ایمیل یا AirDrop بفرستید، نصب پروفایل را بزنید، سپس Settings ← General ← About ← Certificate Trust Settings و اعتماد کامل را فعال کنید.
7. روی تبلت `https://192.168.1.20:3443` را باز کنید. اگر قفل سبز/بدون هشدار بود، HTTPS درست است.

نکته: فایل `rootCA-key.pem` را هرگز جایی نفرستید؛ فقط `rootCA.pem` روی تبلت‌ها نصب می‌شود.

## مسیر ب: سرور واقعی با دامنه (پیشنهادی برای استفاده‌ی عملی)

برنامه پشت یک reverse proxy که خودش گواهی رایگان Let's Encrypt می‌گیرد اجرا شود. ساده‌ترین گزینه **Caddy** است
(یک فایل exe، روی ویندوز هم اجرا می‌شود). شرط‌ها: یک دامنه یا زیردامنه (مثلاً `mad.example.ir`)، آی‌پی عمومی و باز بودن پورت‌های 80 و 443.

فایل `Caddyfile`:
```
mad.example.ir {
    reverse_proxy localhost:3000
}
```
و در `.env` برنامه:
```
TRUST_PROXY=1
REDIRECT_HTTP="on"
HSTS="on"   # فقط بعد از اینکه مطمئن شدید HTTPS پایدار کار می‌کند
```
(در این حالت `HTTPS_KEY_FILE` و `HTTPS_CERT_FILE` را خالی بگذارید.) اگر سرور به اینترنت وصل نیست، Let's Encrypt کار نمی‌کند؛ مسیر الف را با یک CA داخلی دنبال کنید.

برای اینکه برنامه بعد از ریبوت خودش بالا بیاید، آن را با ابزارهایی مثل **PM2** یا **NSSM** به‌صورت سرویس ویندوز اجرا کنید (`npm run build` و سپس `node dist/main.js`، با `NODE_ENV=production`).

## نصب روی تبلت و آزمایش آفلاین

1. در Chrome (اندروید) آدرس را باز کنید، منوی سه‌نقطه ← **Install app / نصب برنامه** (یا Add to Home screen). در Safari (آیپد): Share ← **Add to Home Screen**.
2. یک‌بار با اینترنت وارد شوید تا صفحه و داده‌ها روی دستگاه ذخیره شود.
3. حالت هواپیما را روشن کنید و برنامه را باز کنید؛ باید باز شود و فهرست حضور و غیاب و دانشجویان دیده شود. یک حضور و غیاب ثبت کنید و بعد از وصل شدن اینترنت، ارسال خودکار آن را بررسی کنید.
4. وقتی نسخه‌ی جدید برنامه را جایگزین کردید، مرورگر `index.html` و `sw.js` را کش نمی‌کند؛ تبلت در اولین باز شدن با اینترنت، نسخه‌ی جدید را می‌گیرد (گاهی لازم است برنامه یک‌بار بسته و دوباره باز شود).
